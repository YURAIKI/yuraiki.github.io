데이터 삭제

최종 업데이트 2026년 11월 10일

VidLens는 회원 계정 없이 이용할 수 있습니다. 아래 방법으로 기기에서 분석 기록과 내보낸 파일을 관리할 수 있습니다.

1. 분석 기록 또는 장면 삭제

  • 분석 기록을 지우려면 앱 홈의 최근 작업에서 해당 기록의 삭제 버튼을 누르고 확인하세요.
  • 장면 일부만 지우려면 결과 화면에서 해당 장면을 선택한 뒤 선택 삭제를 누르고 확인하세요.

2. 앱 데이터와 백업 관리

기기에 있는 전체 앱 데이터를 지우려면 Android의 설정 → 앱 → VidLens → 저장공간 → 데이터 삭제를 이용하거나 앱을 제거하세요. 설정 메뉴의 이름은 기기에 따라 다를 수 있습니다. Android 백업에 포함된 기록은 나중에 복원될 수 있으므로, 필요한 경우 기기의 백업 설정에서 백업 사본도 별도로 관리해 주세요.

3. 원본 영상 및 내보낸 파일

앱의 분석 기록을 삭제해도 원본 영상과 이미 내보낸 JPG·PDF·SRT 파일은 남습니다. 내보낸 파일은 파일 관리자에서 Download/Vidlens 폴더를 열어 삭제하세요. 원본 영상이나 다른 서비스에 공유한 사본을 지우려면 해당 파일이 저장된 위치에서 직접 삭제해야 합니다.

4. 문의 정보 및 광고 데이터

회사에 보낸 문의 정보의 삭제를 원하면 support@yuraiki.kr로 요청해 주세요. 회사는 요청을 확인하고 처리 결과를 알려 드립니다. 법령상 보존 의무가 있는 정보는 해당 기간 동안 보관합니다. Google이 처리하는 광고 관련 데이터는 앱에 표시되는 광고 개인정보 설정, Android 광고 설정 또는 Google 데이터 및 개인정보 보호 설정에서 관리할 수 있습니다.
